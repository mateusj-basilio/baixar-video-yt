## Research notes (qualitative only)

Observed competitor title/FAQ patterns (pt-BR), **not** ranked positions or volumes:

- Money landers: “Baixador YT / Conversor YouTube para MP4 / YouTube para MP3 / Baixar Shorts… grátis / sem cadastro / sem instalar.”
- Trust FAQs: gratuito? seguro? sem vírus? funciona no celular? Shorts? playlist? precisa instalar?
- How-to angles: copiar link no app → colar no site → escolher MP4/MP3 → pasta Downloads (Android) / Arquivos (iPhone).
- Safety media: warn about fake Download buttons and adware on generic “baixar vídeo youtube” results — aligns with BaixarVideoYT’s “sem adware” positioning.
- Official Google help often ranks for mobile offline queries (YouTube Premium) — content should clarify file download vs in-app offline.

**Not verified / omitted:** search volume, keyword difficulty, current rankings, CTR, impressions, click estimates for any term above.
